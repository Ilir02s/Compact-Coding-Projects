# Compact-Coding-Projects

Here I insert compact coding projects along the way. My goal is to track my progress.

## Installation

```bash
git clone https://github.com/Ilir02s/compact-coding-projects.git
cd compact-coding-projects
npm install
```

## Usage

```bash
npm start
```
